Revision: 90da0a2bc51724d2b28aef1f3f2a422663a2ede3
Original CSV files and README are retained. Dataset card declares MIT.
Korean labels are bundled separately in ko.json. Autocomplete searches English
tags and Korean labels locally and always inserts the original English tag.
No external translation requests are made while typing.

The Korean dictionary covers 37,697 unique tags outside the artist, character,
and series categories. All 191,110 original unique tags remain available.
Labels were authored with Codex assistance, including explicit clothing-modifier
rules over translated base labels. Proper names may use Korean transliteration;
rare terminology and memes can need further semantic review. This is not an
official Danbooru Korean terminology list. See ko-progress.json for coverage.
