NAI 이야기 요청 구성 규칙

이 프로그램이 NAI 이야기 생성에 보내는 공통 메시지 구성입니다. NAI 전체의 필수 규칙이 아니라 이 작업실의 요청 구성 방식입니다.

  1. 시스템 프롬프트: 요청의 첫 system 메시지. 모델의 역할과 전체 응답 원칙을 지정합니다.
  2. 메모리: 해당 요청에 필요한 인물·장소·지속 상태를 프로그램이 넣습니다. 이 화면에서 직접 수정하는 항목은 아닙니다.
  3. 작가 노트: 별도의 system 메시지. 기존 이야기 앞에, 이야기가 없으면 마지막 작업 지시 앞에 들어갑니다. 기본 노트는 문맥이 없는 요청에서 생략될 수 있습니다.
  4. 기존 이야기: 이어 쓰기에 필요한 앞부분을 assistant 메시지로 넣습니다. 단계에 따라 없을 수 있습니다.
  5. 마지막 작업 지시: ‘기본 지시 앞에 추가’ → ‘전체 지시문 구성’ → ‘기본 지시 뒤에 추가’ 순서로 합칩니다. {{task}} 자리에 프로그램이 만든 실제 작업 지시·사용자 입력·응답 형식이 들어갑니다.

저장한 설정은 이 프로그램의 모든 작품에서 해당 단계에 공통 적용됩니다. 이미 완성된 컷과 그림은 바뀌지 않습니다. 저장된 요청을 재시도하면 당시 문구를 사용하므로, 변경 효과는 새 요청에서 확인하세요.

확인 순서: 단계 선택 → 사용할 때 설명 확인 → 문구 수정 → ‘입력값으로 전송 미리보기’ → 최종 메시지 확인 → 저장. 미리보기와 저장은 AI를 호출하지 않습니다.

저장된 프롬프트와 전송 기록을 불러옵니다.
